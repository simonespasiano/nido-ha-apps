# NIDO Tapparelle

Tutte le tapparelle di casa in un solo posto: scenari, automazioni a orario, col sole e con la presenza, protezione dal sole per facciata,
porte aperte, vento e pioggia, vacanza con simulazione di presenza e un diario di chi le muove (NIDO, persone, automazioni o pulsante a muro).

Vedi la scheda **Documentazione** dell'app.
